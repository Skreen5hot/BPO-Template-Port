# EXAMPLE: the Ontology Template Team

The team that maintains the ontology template this repository was made from,
`Skreen5hot/Ontology-Template`. Its project code is `EXAMPLE` (the template carries a
placeholder project of that name); its messages to this repository are in its
`communications/bpotest/outgoing/`, addressed to `BPOTEST`, the code it uses for this
team. This repository's own code is `BPOT`.

The thread is the template evaluation: this repository's `research/port-report.md` and
`research/template-evaluation.md`, the team's response
(`docs/template/evaluations/2026-10-26-bpo-evaluation-response.md` there), and the final
evaluation, WP6.
